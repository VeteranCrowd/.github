# VeteranCrowd/.github

Organisation-wide GitHub defaults for [VeteranCrowd](https://www.veterancrowd.com/).

- **`profile/README.md`** is the profile shown on the [VeteranCrowd organisation page](https://github.com/VeteranCrowd).
- **`.github/pull_request_template.md`** is the default PR template. GitHub uses it for every VeteranCrowd repo, public or private, that has no template of its own.

GitHub uses default community health files (issue and PR templates, `CONTRIBUTING`, `SECURITY` and so on) only from this repo, which must stay **public**. Keep everything here fit for public view.

Copilot instructions can't be served from here: each repo keeps its own `.github/copilot-instructions.md`.
